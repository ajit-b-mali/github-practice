for that I need to create a service file at '/etc/systemd/system/github-practice.service' It will run as deploy, use node26 installed via deploy's nvm, restart on failure and start automatically after reboot. The only catch with systemd is that it don't know node executable path I need to put that in service file.

I got the path from 'which node' command its '/home/deploy/.nvm/versions/node/v26.13.1/bin/node'. I need to create github-practice.service file as root. and wrote this

```

[Unit]
Description=GitHub Practice Node.js API
After=network.target

[Service]
Type=simple
User=deploy
Group=deploy
WorkingDirectory=/opt/apps/github-practice
ExecStart=/home/deploy/.nvm/versions/node/v26.13.1/bin/node /opt/apps/github-practice/server.js
Restart=always
RestartSec=5
Environment=NODE_ENV=production
Environment=PORT=3001

[Install]
WantedBy=multi-user.target
```
